# Carpeta para Capturas de Testimonios y Fondeos

Puedes guardar aquí las capturas reales que tomaste de WhatsApp y FundingPips con estos nombres exactos (o cualquier nombre que desees):

- `lucas-fundingpips.jpg` -> Captura del correo de FundingPips / mensaje de Lucas
- `franco-alonso.jpg` -> Captura de WhatsApp de Franco
- `juanse-mentalidad.jpg` -> Captura de WhatsApp de Juanse
- `alumno-fondeado.jpg` -> Captura de WhatsApp del alumno fondeado
- `alexandra-comunidad.jpg` -> Captura de WhatsApp de Alexandra
- `guion-de-vida.jpg` -> Captura del guion de vida

La web detectará automáticamente los archivos y los mostrará en alta definición con zoom interactivo.
Si no hay un archivo todavía, mostrará un diseño estilizado idéntico a WhatsApp Dark Mode.
